## Places this differs from the spec, for the reviewers to challenge

| Item | Spec | Built | Why |

| Failed inbound auth | 05-api 14.3: 403 `forbidden` | 404 `route_not_found`, identical to a missing route | Coordinator's instruction. The cost is that Postmark keeps retrying a mistyped URL instead of stopping; a 403 would drop that message from retries |

## Known ceilings

- The flood cap counts then inserts, so concurrent deliveries can pass 400 by a few rows. A per-user advisory lock makes it exact if that ever matters.
- A failing body-size gate answers 503 `Retry-After: 3` (`bodyPermit`'s value), not the spec's 5. Postmark retries either way.
- `inbound_body` retention can't use `inbound_emails_body_purge_idx` while it also looks at the legacy plaintext. That goes with the column in WP-46.
