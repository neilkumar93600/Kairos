# WP-31 frontend handoff: AI review with level, tags and headline

Nothing in `web/` was changed. `POST /api/resumes/suggestions` now exists, matching the contract in `shared/src/schemas-suite.ts` and the QA mock. Wait for the live eval before pointing production at it (`owner-actions/WP-31.md`).

## The route

- Body: `resumeSuggestionRequestSchema`: `scope` (now with `headline`), `resumeId`, optional `level`, plus today's fields. No `level` means the resume's stored level, then a tailored copy's posting seniority, then the highest level in preferences, then mid.
- Response: `{ suggestions, factCreated }`. Suggestions carry `tag` and `priority`. On a pin to v1 they do not, so keep both optional when rendering.
- Added to the contract: 409 `read_only` for a copy that was sent, and 503 `ai_unavailable`. A headline also answers 503 while v1 serves the call: show "try again later", not an error about the headline.
- An empty `suggestions` is a valid 200: "No suggestion this time".

## Saving a headline

`PUT /resumes/:id` now holds `headline` to the truth lock. On failure it answers 422 `truth_lock` with `"headline"` in `details.lineIds`, and the rule in `details.reasons.headline`.

- Save `{ text: suggestion.after, factIds: suggestion.factIds }` as it came.
- A trailing ` · N years` is accepted only when N equals what the server computes from confirmed role dates today. If the user edits the number, the save fails.
- The server counts months covered by confirmed roles, overlaps once, gaps not at all. The QA mock's `yearsOfExperience` takes earliest start to latest end, so it can show more than the server. Show `derived[0].value` from the response, never your own computation.

## Level-aware checks stay in the browser

The server stores no check score, and `ResumeSummary.checkScore` stays null. Apply PRD 8.1 and 8.2 in `web/components/resume/model.ts`:

| Check | Early career | Mid | Senior | Lead |
|---|---|---|---|---|
| Page length warning above | 1 | 2 | 2 | 3 |
| Lines, two most recent roles | 5 | 6 | 6 | 6 |
| Lines, older roles | 4 | 3 | 3 | 2 |

Also from 8.2: repeated words, double spaces, date formats, the cliché list, metric use, tense. These decide nothing on the server.

## Not done by this package

The server's PDF, DOCX and text renderers do not print `headline` yet (`grep headline` finds no renderer code). PRD 8.4 says every template shows it, so this belongs to the renderer package.
