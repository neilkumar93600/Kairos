
## 2. Landing copy: keep the gated guarantee line off

File: `web/content/landing-copy.ts:207-209`. `guaranteeLive` ("Failed submits cost nothing. Billing pauses when an offer email arrives.") is gated behind G3 and must not ship while the automatic pause is gone. Either keep it gated or change it to "Failed submits cost nothing." until the confirmed-pause flow (offer_pause_candidates, 48-hour undo) is built.

## 3. Cloud channel is owner-only for now

`POST /api/applications/approve` with `channel: "cloud"` answers `403 { error: { code: "forbidden", message: "The cloud applier is not open yet" } }` for everyone except the user ids in `OWNER_USER_IDS`. `GET /api/me` does not tell the web who is an owner. Until WP-04 opens the channel, hide the cloud option in the approve UI for non-owners, or show the message above on a 403. The extension channel is unchanged.

## 4. Checkout and imported boards

- Stripe Checkout no longer shows a promotion-code field (`allow_promotion_codes: false`). Remove any pricing or billing copy that mentions promo codes (none found in web/ on 2026-10-30).
- A pasted job link now stores its company as inactive. The imported posting still works for the importing user (match, tailor, apply); the board is simply no longer polled, so a closed posting is not detected automatically. No web change needed; mention only if the import UI promises "we will watch this company".
- Inbox: the `preview` field is now cut to 280 characters in SQL. Response shape is unchanged.
