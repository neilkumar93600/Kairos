# WP-07 frontend handoff

WP-07 adds one error code, widens one existing refusal, stops one onboarding regression and needs one legal-copy change. No response shape changes. Nothing in web/ was edited by this package.

## 1. DELETE /api/profile/facts/:id can answer 409 fact_cited (new)

A confirmed fact that an application's resume lines or the base resume cite (a line's `factIds` or an entry's `headingFactId`) is no longer deleted:

```json
409 { "error": { "code": "fact_cited", "message": "This fact is cited by your resume or an application, so it cannot be deleted" } }
```

Unconfirmed facts, uncited facts, and missing or foreign ids still answer 204 as before. Note: this tightens 05-api.md 12.2 ("DELETE is 204 whether or not the row existed", citations "none of which is an error on this route") on purpose (database-v09: a sent application must never cite a fact that no longer exists).

File: `web/components/dashboard/profile/fact-list.tsx:55-59`. Today a failed delete shows the generic error with a retry, and the retry would fail the same way. On `ApiError` with `code === "fact_cited"`, show the server message (or "This fact is used in your resume or an application. Change those lines first.") and do not offer the retry. Facts behind sent applications stay for good; the copy should not suggest otherwise.

## 2. POST /api/applications/:id/drafts refuses profile questions by label (widened)

`422 profile_only` now also covers any answer whose label mentions name, email, phone, mobile, telephone, LinkedIn, GitHub, portfolio, website, URL, address, city or location, whatever the answer's `source` is. Before, these were refused only while `source` was `"profile"`, and a PATCH (which rewrites every source to `"user_edit"`) reopened them to the model.

`web/components/dashboard/queue/draft-assist.tsx:46` already handles `profile_only`, so nothing breaks. Optional: hide "Draft with AI" up front for those labels. The match is deliberately broad, so a free-text question such as "How would you address a conflict?" is refused too; the user writes that one by hand.
