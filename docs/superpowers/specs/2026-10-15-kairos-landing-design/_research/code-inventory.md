### next.config.ts

- `cacheComponents: true` and `partialPrefetching: true`. Pages prerender by default, so any runtime data read (cookies, headers, uncached fetch) must sit under `<Suspense>` or a cache boundary. The landing has no data reads, so it stays static.
- `transpilePackages: ["@auto-career/shared"]`.
- Turbopack rule: `"*.css"` loaded through `@tailwindcss/turbopack`. Keep this rule when editing CSS.
- Security headers on `/:path*`: `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `X-Frame-Options: DENY`, `Permissions-Policy: camera=(), microphone=(), geolocation=()`. No Content-Security-Policy is set. Any WebGL or script addition must not assume one.

### tsconfig.json

- `strict: true`, `noEmit: true`, `isolatedModules: true`, `moduleResolution: "bundler"`, `jsx: "react-jsx"`, `target: ES2017`, `lib: ["dom","dom.iterable","esnext"]`, `incremental: true`, `plugins: [{ "name": "next" }]`.
- Path alias: `"@/*": ["./*"]`. Use `@/components/...`, `@/lib/...` and `@/hooks/...`.
- Include: `next-env.d.ts`, `**/*.ts`, `**/*.tsx`, `.next/types/**/*.ts`, `.next/dev/types/**/*.ts`, `**/*.mts`. Exclude `node_modules`.
- Typed layouts: `app/layout.tsx` and `app/(public)/layout.tsx` type props as `LayoutProps<"/">`, a global helper generated by `next typegen`. The `typecheck` script runs `next typegen && tsc --noEmit`, so run that script rather than bare `tsc`.

### eslint.config.mjs

- Flat config (ESLint ^9). Extends `eslint-config-next/core-web-vitals` and `eslint-config-next/typescript`, then `globalIgnores` for `.next/**`, `out/**`, `build/**`, `next-env.d.ts`.
- `npm run lint` runs `eslint` with no arguments. Core Web Vitals rules apply, so use `next/image` for images, `next/link` for internal links, and `next/font` for fonts. The react-hooks rules shipped in that preset also apply to any WebGL or scroll code.

## 2. Root layout and fonts: current state versus the brief

### Current

- `web/app/layout.tsx` imports `Inter` from `next/font/google` with `{ variable: "--font-inter", subsets: ["latin"], weight: "400" }`. The comment says it substitutes for Lausanne.
- The `<html>` element gets `${inter.variable} h-full antialiased`. `<body>` gets `flex min-h-full flex-col`.

- `globals.css` maps `--font-sans: var(--font-inter)`. `body` sets `font-feature-settings: "ss01" on` and `font-weight: 400`.

- UI and body: Inter Variable, weights 400 and 500. Weight 500 for buttons, nav and card titles. Weight 400 for paragraphs. `cv11` enabled.
- No weight above 500. `tabular-nums` for numbers in tables and counters.

## 4. Blast radius of moving globals.css to the dark tokens

### Why the change is app-wide

`globals.css` defines tokens on `:root` and exposes them through `@theme inline` as `--color-*`. Tailwind utilities such as `bg-background`, `bg-surface`, `text-muted`, `border-line`, `bg-accent`, `text-accent-ink`, `text-good`, `text-warn`, `text-bad` and `bg-smoke` resolve through those tokens everywhere. `body` also sets `background: var(--background)` and `color: var(--foreground)`. A grep found 56 files under `web/app` and `web/components` that use one of these token utilities. There is no route scoping, so every route changes when the tokens change. Brief open item 2 already accepts this.

## 6. Constraints any landing code must respect

1. Use `@/` imports for anything outside the current folder. Existing landing files use `../shared/...` relative imports; either style compiles, but match the file you are editing.
2. Default to Server Components. Mark a file `"use client"` only when it needs state, effects, `window`, WebGL or scroll listeners. Load WebGL through a client component with `next/dynamic` and `ssr: false`.
3. Pages must prerender under `cacheComponents: true`. Do not read cookies, headers or uncached data in the landing.
4. Layouts keep the `LayoutProps<"/">` typing. Run `npm run typecheck` (it runs `next typegen` first).
5. Lint must pass with `npm run lint` under `eslint-config-next/core-web-vitals` and `/typescript`.
6. Fonts come only from `next/font/google`. No `<link>` font tags. Weights 400 and 500 only.
7. Tailwind 4 CSS-first. New tokens go in `:root` and `@theme inline`. Keep the `"*.css"` Turbopack rule in `next.config.ts`.
8. Adding `motion`, `three`, `@react-three/fiber`, `@react-three/drei` or a smooth-scroll library is a new dependency. The package list shows none is installed. Use `motion` (not `framer-motion`) if motion is added.
9. Phones: 16px side gutter from `Container`, and no horizontal page scroll. The comparison table already uses `overflow-x-auto` inside a `min-w-[640px]` table, which is the only sanctioned horizontal scroll.
10. Keep `/how-it-works`, `/pricing` and every other route unchanged while the landing changes. Landing-only treatments go in `components/landing/`, not in `components/shared/`.
11. Next 16 has breaking changes against older training data. `web/AGENTS.md` points to `node_modules/next/dist/docs/`, which is not installed. Use nextjs.org/docs for `next/font`, `next/dynamic`, `proxy.ts` and `cacheComponents`.
